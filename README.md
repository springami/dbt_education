# settings
**Для создания виртуального окружения вводим команду
```bash
python -m venv venv
```

** Для активации виртуального окружения вводим
```bash
venv\Scripts\Activate
```
# либо можно попробовать команду
```bash
venv\Scripts\Activate.ps1
```

**В случае если будет ошибка ```так как выполнение сценариев отключено в этой системе```**
открываем PowerShell от имени Администратора и вводим команду и отвечаем A - для всех
```bash
Set-ExecutionPolicy RemoteSigned
```
